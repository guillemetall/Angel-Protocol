📡 Angel Protocol Installer

Offline mesh messaging for the XIAO ESP32-C6

Requirements: Chrome or Edge on a desktop computer (Windows, macOS, Linux). Mobile browsers do not support Web Serial yet.

Install firmware

  1. Connect the XIAO ESP32-C6 to your computer with a USB-C cable.
  2. Click the button below.
  3. Select the serial port when prompted.
  4. Wait for the installation to finish (about 30 seconds).
Your browser does not support Web Serial. Use Chrome or Edge. Web Serial is not allowed. Use HTTPS.

After installation

  1. Disconnect and reconnect the board.
  2. Open nRF Connect on your phone.
  3. Scan for XIAO-MESH.
  4. Connect with passkey 123456.
  5. Press the button on the board to confirm pairing.
Mobile users: use the ESP32_Flasher app on Android instead. See the README for instructions.
