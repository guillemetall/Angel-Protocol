# Angel Protocol Firmware Installer

Web-based firmware installer for the XIAO ESP32-C6.

## Requirements

- Chrome or Edge browser
- Desktop computer (Windows, macOS, Linux)
- USB-C cable

## How to use

1. Go to https://guillemetall.github.io/Angel-Protocol/
2. Connect the board by USB-C
3. Click "Install Angel Protocol"
4. Select the serial port
5. Wait for completion

## Where do the .bin files go?

Place `bootloader.bin`, `partition-table.bin`, and `xiaomesh.bin` in this folder before publishing.
